## ❌ 5. 44px 미만 탭 타깃 — 심각

가장 큰 위반이다. §0 절대 규칙 "모든 탭 타깃 ≥ 44px"를 어긴 곳.

### 5-a. 모바일 (실제 손가락이 닿는 곳 — 반드시 고쳐야 함)

| 화면 | 노드 | 현재 크기 | 비고 |
|---|---|---|---|
| M2 일정표 | `Chip/W01`~`Chip/W06` (6개) | 51×**32** | 주차 필터 칩 |
| S7 아코디언닫힘 | `Chip/W01`~`Chip/W06` (6개) | 51×**32** | 위와 동일 컴포넌트 |
| M4 내 기록 | `Chip/전체`·`Chip/과제`·`Chip/노트` | 48×**32** | 타입 필터 칩 |
| S6 빈 상태 | `Chip/전체`·`Chip/과제`·`Chip/노트` | 48×**32** | 위와 동일 |

→ 필터 칩 전부가 32px다. 모바일에서 가장 자주 누르는 요소 중 하나인데 12px 부족하다.

### 5-b. 데스크톱 / 관리자 (마우스 기준이라 44px 강제는 과하나, 기준상 위반)

| 화면 | 노드 | 현재 크기 |
|---|---|---|
| D2 상세 | `Btn/뒤로` | 56×32 |
| D3 내 기록 | `Chip/전체`·`Chip/과제`·`Chip/노트` | 56×36 |
| A1 승인함 | `Btn/일괄 승인` 83×36, `Btn/반려` 56×36, `Btn/승인` 56×36 (행마다) | 36 |
| A1 승인함 | `Checkbox` | **20×20** ← 가장 작다 |
| A1 승인함 | `Btn/슬랙원본` | 79×**28** |
| A1 승인함 | `Select/일정` | 218×36 |
| A2 일정관리 | `Select/판교 1반` 93×36, `Select/주차 전체` 97×36 | 36 |
| A2-a 인라인편집 | `Field/*` 4개, `Btn/저장`, `Btn/취소` | 40 |
| A2-b 삭제경고 | `Select/*` 2개 | 36 |

→ 판단 필요: **관리자·데스크톱은 36px를 허용할지, 아니면 기준을 그대로 밀지.**
→ 단 `A1 Checkbox 20×20`은 데스크톱 기준으로도 작다. 최소 히트영역 32px 이상 권장.

## ❌ 6. 핑크를 '오늘' 이외의 의미로 사용 — 2건

§3.1.1 "핑크(`$today`/`$today-vivid`/`$today-soft`)는 오직 '오늘'에만 쓴다"를 어긴 곳.

| 화면 | 노드 | 사용 | 실제 의미 |
|---|---|---|---|
| A1 승인함 | `Item/실습 코드 저장소 › Select/일정` (stroke `$today`)<br>`Row3/Guess` (fill `$today-soft`, 아이콘·글자 `$today`) | 핑크 | **"⚠ 추정"** — 경고이지 오늘이 아니다 |
| A2-b 삭제경고 | `Dialog/Head/IconBox` (fill `$today-soft`) | 연핑크 | **삭제 경고** — 오늘이 아니다 |

→ 둘 다 `$danger`(#B91C1C) 계열 또는 별도 `warning` 토큰으로 빼는 게 맞다.
→ 참고: `Badge/week-current`가 `$today-soft`를 쓰는 것도 엄밀히는 '이번 주'이지 '오늘'이 아니다. 경계 케이스로 남겨둠.

## ⚠️ 10. 데스크톱 전용 기능 — 1건

화면별 액션 요소 전수 비교:

```
M1 : Composer                                D1 : Composer                    → 일치
M2 : Chip/W01~W06                            (모바일 전용 화면)
M3 : Composer                                D2 : Btn/뒤로, Composer          → Btn/뒤로만 추가
M4 : Chip/전체·과제·노트, Btn/더보기          D3 : Chip/전체·과제·노트, Btn/더보기 → 일치
M5 : Btn/슬랙        M6 : Btn/시작하기
```

- `D2 › Btn/뒤로`는 모바일 `AppHeader › Back`의 데스크톱 대응이므로 **기능 추가 아님.**
- **A1 `Btn/일괄 승인`(다중 선택 일괄 처리)이 유일한 데스크톱 전용 기능이다.** 다만 관리자 화면은 §6에서 "데스크톱만 만든다"로 명시했으므로 위반이 아니라 **승인 대기 중인 §16 이탈 항목 6번**에 해당한다.

## ✅ 통과 항목 상세

**2. 등록 폼의 일정/폴더/태그 선택 UI 없음** — `Composer/Expanded` 마스터 및 M1/M3/D1/D2 인스턴스 전수 확인. 일정 선택 컨트롤 없음, 읽기 전용 확인 문구(`ContextText`)만 존재. 통과.

**3. 빈 상태** — S6 `EmptyState`는 아이콘 + `Message`("아직 기록이 없습니다") + `Sub`("오늘 강의는 Java/Spring 기초입니다. 한 줄만 남겨도 포트폴리오가 됩니다") + 액션 버튼 4단 구성. S2·S5도 동일 패턴. 한 줄로 끝나는 곳 없음.

**4. 375 넘침** — 모바일 14개 프레임의 직속 자식 트리 절대 좌표 검사, `x < 0` 또는 `x + width > 375` 없음. 스크린샷 육안 확인 일치.
※ 375×812 고정 + `clip:true`이므로 **세로** 폴드 아래는 의도적으로 잘린다(M1 4번째 카드 등). 이건 위반 아님.

**8. 그라데이션** — 총 7곳, 전부 `ProgressTrack/Fill`. 진행 바 이외 사용 없음.

## [X] 추가 발견: 컴포넌트 인스턴스 렌더링 불일치

`01 · Components` 갤러리의 Composer 변형 인스턴스 3개가 **마스터와 다른 크기로 렌더된다.**

| 인스턴스 | 노드 | 마스터(`CrFdG`) | 인스턴스 렌더 |
|---|---|---|---|
| `PoRma` Composer/입력완료 | `Seg/노트`, `Seg/과제` | 44 | **36** |
| `gWXww` Composer/저장중 | `Field/Title` | 44 | **21** |
| `JSPmi` Composer/파일첨부 | `Btn/파일`·`링크`·`취소`·`저장` | 44 | **20** |
|  | `Chip` | 44 | **30** |

- 세 인스턴스의 `descendants` 오버라이드를 확인했으나 **height 오버라이드는 없다.** 내용·색·opacity만 덮어쓴다.
- 마스터 `CrFdG` 단독 스크린샷은 44px로 정상 렌더된다.
- **실제 화면(M1/M3/S3/D1/D2)의 Composer 인스턴스는 44px로 정상.** 갤러리 3개만 어긋난다.
- → Pencil의 인스턴스 해석 캐시 문제로 보인다. 갤러리를 다시 만들면 해소될 가능성이 높다. 실사용 화면에는 영향 없음.
