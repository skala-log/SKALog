## 0. v2가 왜 실패했는지 (자기 점검)

실제로 Pencil에 만들어봤다: 옅은 보라색 사각형(탭) + 카드(몸통) 두 개를 겹쳤다. 스크린샷으로 확인하니 **폴더로 안 읽히고, 그냥 라벨이 어긋나게 붙은 것처럼 보였다.** "겹친 flat 도형 두 개"라는 논리 자체는 맞았지만, 크기·비율·디테일이 너무 절제돼서 스큐어모피즘이 주는 "손이 많이 간 느낌"이 하나도 안 남았다.

더 근본적인 문제: **폴더라는 형태에 매달린 게 애초에 방향 착오였다.**
- 사용자가 좋아한 건 "폴더" 그 자체가 아니라 SKALA HUB 화면이 주는 **예쁘고 개성 있는 인상**이었다. 폴더는 그 인상을 준 여러 예시 중 하나였을 뿐.
- SKALA HUB의 폴더 UI는 "정보를 카테고리별로 인덱싱해서 보여준다"는 **기능적 목적**을 가진 디자인이다. SKALog는 원칙 1("분류를 시키지 않는다")이 서비스의 핵심 축이라, 애초에 인덱싱이 필요 없다. 기능이 다른 화면에서 형태만 떼어오려니 어색했던 것.

**정정된 목표**: 지금 화면의 정보 구조·클릭 흐름·컴포넌트 배치는 전혀 안 건드리고, 그 위에 순수하게 "예쁨"만 더하는 장식 기법을 찾는다. 특정 형태(폴더)에 미리 갇히지 않는다.

## 1. 후보 (폴더에 얽매이지 않고 넓게)

### A. 커스텀 듀오톤 아이콘 세트

지금 쓰는 lucide 라인 아이콘은 기능적으로는 충분하지만 개성이 0이다. 과목·자료 종류·빈 상태처럼 반복적으로 등장하는 자리에, 선+면이 같이 있는 **duotone(두 톤짜리) 커스텀 아이콘**을 쓰면 손이 많이 간 느낌을 준다 — SKALA HUB 폴더도 결국 "두 톤 면"으로 입체감을 낸 것과 같은 원리를, 폴더가 아닌 다른 형태(책·문서·코드 등 실제 자료 종류를 은유하는 아이콘)에 적용.

```
지금:  🗎 (단색 선 아이콘)
제안:  ▤▥ (연한 면 + 진한 선을 겹친 duotone 아이콘, 자료 종류별로 형태도 다르게)
```

### B. 소프트 볼륨 배지 (그림자 아닌 이중톤 하이라이트)

핵심 브랜드 요소(오늘 배지, 저장 버튼, 주차 번호처럼 자주 보고 눌리는 소수)에만, 그림자 대신 **밝은 톤 하이라이트 한 겹을 위쪽에 살짝 얹는** 방식으로 볼륨감을 준다. 진짜 스큐어모피즘의 "빛이 위에서 온다"는 원리를 아주 절제해서 차용 — 그림자 규칙(3.3절)은 그대로 유지하면서 입체감만 미세하게 추가.

```
지금:     ╭────────╮
          │  오늘   │   (단색 채움)
          ╰────────╯

제안:     ╭────────╮
          │▔▔▔▔▔▔▔▔│  ← 위쪽 1/3 정도만 한 톤 밝게
          │  오늘   │
          ╰────────╯
```

### C. 브랜드 심볼 / 마스코트

SKALog만의 작은 심볼 하나를 만들어서 로그인 화면·빈 상태·저장 완료 순간처럼 "사용자가 잠깐 멈추는 자리"에 반복 노출한다. SKALA HUB의 "귀여운 폴더"가 주는 개성을, 형태를 베끼지 않고 **SKALog 고유의 마크**로 대체하는 방향 — 예: 책갈피와 체크마크를 합친 모양, 혹은 필기감이 느껴지는 언더라인 획 하나.

```
로그인 화면:
        ⌘
     SKALog
  설정 없이 바로 쓰는 학습 기록장
```

### D. 종이 질감 / 그레인

완전 플랫한 단색 배경 대신, 아주 미세한 종이 그레인(노이즈) 텍스처를 배경에 깔아 "기록장"이라는 이름에 맞는 물성을 준다. 형태를 바꾸는 게 아니라 **재질**을 바꾸는 접근이라 지금 레이아웃·컴포넌트에 전혀 손 안 대고 적용 가능 — 리스크가 가장 낮은 안 중 하나.

### E. 종이 모서리 접힘 (dog-ear)

카드·기록 항목 우측 상단에 종이가 살짝 접힌 듯한 작은 삼각형을 넣는다. "물리적 다이어리를 넘기는" 은유라 SKALog 브랜드(기록장)와 잘 맞고, 폴더보다 훨씬 미묘해서 과하지 않다.

```
┌─────────────────────────┐╲
│  강의자료                 │ ╲  ← 우상단 모서리만 살짝 접힌 것처럼
│  Spring DI 개요.pdf   ↓  │
└─────────────────────────┘
```

### F. 완료 스탬프 (v2에서 이어옴)

기록 저장 직후, 주차 완주 시점처럼 의미 있는 순간에 실제 도장을 찍은 듯한 질감의 원형 마크가 잠깐 나타난다. 상시 장식이 아니라 **모먼트에만** 쓰여서 화면 전체 톤을 안 흔든다.

## 2. 이번엔 검증 순서를 바꾼다

지난번엔 텍스트 설명만 보고 판단이 안 서서 Pencil로 만들어봤는데, 막상 만든 게 별로였다. 이번엔 후보를 고르면:
1. 고른 방향에 대해 **더 구체적인 스케치/설명**을 먼저 드리고 (여전히 텍스트/이 문서 단계)
2. 그게 괜찮아 보이면 그때 Pencil로 1개 화면에만 시범 적용
3. 확인 후 나머지 화면에 확산

한 번에 "만들어서 보여주기"로 안 건너뛴다.
